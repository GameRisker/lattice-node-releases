# Lattice Node 安装包

本仓库仅公开安装器、已签名的 Codex Node 安装包、公钥和校验摘要。不包含 Lattice 应用源码、私钥或账号配置。

## 安装

1. 打开 https://hub.gamerisker.com 的「节点 → 接入新节点」。
2. 复制网页的一条安装命令，在目标电脑终端执行。
3. 在安装器提示时输入网页的一次性连接码。安装器会校验安装包、配对并启动节点。
4. 选择登录 ChatGPT / Codex 账号，在自己的浏览器打开终端显示的官方地址并输入设备码。缺少 Codex CLI 时会下载并校验官方程序，仅安装到节点私有目录。

支持 Apple 芯片 Mac、x64 Linux 和 ARM64 Linux；无需 Go。工作目录和执行权限仍需单独确认。已有节点身份不会被覆盖。

安装器内置发布公钥指纹、校验器摘要与该工作台的公开签名密钥；工作台不能替换这些独立信任根。请从本仓库的正式 Release 获取安装器，勿执行其他来源的脚本。

## 状态与停止

程序默认位于 `~/.local/bin/codex-node-agent`，配置默认位于 `~/.codex-node-agent`。

运行 `~/.local/bin/codex-node-agent status` 检查；运行 `~/.local/bin/codex-node-agent stop` 停止。卸载程序前先停止，保留配置可保留已配对身份；再次执行安装器不会自动覆盖已有身份。

安装和在线不代表已完成真实模型任务；真实设备和模型验收状态见私有项目计划。

## 已安装节点的账号认证

先在网页更新已有节点程序，再在该节点终端运行：

```sh
~/.local/bin/codex-node-agent auth setup
```

按终端提示完成设备码登录；账号凭据留在本机，不上传到工作台。无法启用设备码时，检查 ChatGPT 个人安全设置或工作空间权限。非交互安装或 `--skip-auth` 会跳过登录，可以稍后执行上述命令。登录与工作目录、任务执行授权分别确认。
